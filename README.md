# ZenOS RC0 — Base House Candidate

ZenOS is a repository-based environment for human and intelligent participants
to collaborate through explicit intent, bounded delegation, observable
evidence, and shared stewardship.

This repository is a **private release candidate for falsification**. It is not
yet a public release, a client instance, or a claim of production fitness.

Start with [WELCOME.md](WELCOME.md). A steward establishing a new instance then
follows [ONBOARDING.md](ONBOARDING.md). AI participants begin with
[AGENTS.md](AGENTS.md).

## What travels

- the complete RFC-0000 through RFC-0007 constitutional library;
- the minimum dependency-closed repository layout;
- templates for the first operating loop;
- six host-neutral constitutional checks and one fail-closed runner;
- progressive arrival, contribution, security, governance, support, and update
  guidance; and
- provenance and a deterministic allowlist manifest.

## What does not travel

No living-house history, participant roster, evidence, warrant trail, client
data, credentials, runtime configuration, generated status, or application
fixture is present. A receiving steward creates the first real institutional
records locally.

## Repository authority

Plain files remain canonical. Git is the recommended history substrate. Any
interface or automation is a view or participant under the same rules; neither
becomes a second source of truth.
