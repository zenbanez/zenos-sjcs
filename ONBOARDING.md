# Instantiate a Local House

This procedure creates the first real institutional relationships. It does not
contact an upstream service and does not grant authority automatically.

## Before you begin

- Choose one human who accepts initial stewardship responsibility.
- Configure Git with that person's real local commit identity.
- Keep the repository private until local disclosure and security review say
  otherwise.
- Never place credentials, private keys, databases, backups, or client data in
  the repository.

## Bootstrap

1. Copy the templates into real records, replacing every `{{PLACEHOLDER}}`.
2. Create `participants/humans/<steward-id>.md` and map the Git author string in
   `participants/authors-map.md`.
3. Mint `INT-0001` as the local founding intent. Only the human steward assigns
   that top-level ID.
4. Create `workspaces/WS-0001-<slug>/workspace.md` and `delegations.md` mounted
   to the intent.
5. Register the first participant before their first direct commit, or in that
   same commit.
6. Append the participant's root commission warrant to
   `evidence/warrants/<issuer>/YYYY/MM.jsonl`; bind its `content_hash` to the
   exact governing intent bytes.
7. Update `intents/progress/INT-0001.md` and `intents/progress/index.md` as
   linked read models.
8. Commit the candidate and run:

   ```text
   python .github/scripts/run_checks.py
   ```

9. Open a branch contribution. A green guard is mechanical evidence, not merge
   consent; the steward still reviews and accepts the change.

## Optional scaffolder

`python tools/bootstrap_instance.py --help` can create a deterministic
synthetic or local draft from explicit arguments. Review every generated byte
before committing. The script scaffolds relationships; it does not authorize
them.

## Completion test

A minimum instantiated house has a Constitution, one intent, one workspace,
one participant and author mapping, one bounded delegation, one root-anchored
warrant trail, one cited knowledge candidate or concept, and one decision.

Record every place where these instructions require outside explanation. That
friction is evidence for improving the next release, not a reason to conceal
intervention.
