# References — the school's own materials

**Filled, 2026-09-08 — mostly.** Three groups are here: the official MATATAG
curriculum guides for K–6, the DLL/DLP template with a plain-text transcription
of the scanned original, and Division L&D/TPD context carried from
`zenos-deped`. Copied into the USB distribution the same day under D-007, so
the two directories match.

**Still the steward's alone, per D-002:** SJCS's own assessment or rubric
templates, and the school calendar for the current quarter. Neither blocks the
day; both would make the 13:00 block land closer to real work.

## What belongs here

The materials the day's work should be shaped by:

- the Daily Lesson Log template teachers are required to use;
- the lesson plan format expected at this school;
- curriculum guides for the learning areas actually present in the room —
  check who is attending;
- assessment or rubric templates already in use;
- the school calendar for the current quarter.

The same set is copied into the distribution that goes on the USB sticks. They
should not drift apart: if a template is corrected here, the sticks are stale.

## Why these were not drafted in advance

They are DepEd instruments held by the facilitator and the school. Writing
plausible versions would put fabricated departmental documents in front of
thirty teachers, and every lesson plan produced from them would inherit the
error — discovered, if at all, only after the material had been taught.

This folder being empty is a deliberate gap, not an oversight.

## Two checks before anything is copied

**Personal data.** Blank templates are safe. Filled-in samples frequently carry
learner names, parent names, or contact numbers. Anything going onto thirty USB
sticks is effectively published to thirty households; check each document
before it goes in, not after.

**Format.** Prefer `.docx`, `.txt`, `.md`, `.csv`. A scanned PDF of a form is an
image, and an AI client reads it poorly or not at all. If the only copy of a
template is a scan, retyping the blank fields into a plain document is worth
the effort — a template the client cannot read is a template the room cannot
use.

## Rights

These are institutional documents, held here for the school's own work. Nothing
in this folder is cleared for redistribution, publication, or use outside this
house, and this repository stays private.
