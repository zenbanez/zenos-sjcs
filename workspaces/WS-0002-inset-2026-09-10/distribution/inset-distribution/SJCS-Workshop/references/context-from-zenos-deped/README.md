# L&D / TPD context, carried over from `zenbanez/zenos-deped`

## What this is

The PPST framework and the Abridged Learning and Development System for
Teacher Professional Development (TPD) booklets, already evidence-admitted in
`zenbanez/zenos-deped` on 2026-08-11 and 2026-08-12. Copied here verbatim, at
the steward's direction, as background/competency-alignment context for the
10 September INSET.

- `2026-08-11-ppst-framework/` — the PPST domain/strand/career-stage matrix,
  and DepEd Order 42 s. 2017, the order that formally adopted it.
- `2026-08-11-abridged-tpd-booklets/` — the seven-part draft Abridged L&D
  System for TPD booklets (Governance, Needs Assessment, Planning, Program
  Designing, Resource Package Development, Delivery, QA/M&E).
- `2026-08-12-ksa-job-aid/` — Annex C, the KSA job aid for identifying
  teachers' learning needs by knowledge, skills, and attitudes across the
  PPST domains.
- The two `*-admission.md` files are copied unchanged from `zenos-deped` —
  they are that house's own admission record for these documents, kept here
  for provenance, not rewritten as this house's own admission.

## What this is NOT

**This does not fill the gap `../README.md` (this workspace's own
`references/`) describes and D-002 still holds open.** These are
Division-level program-management documents — how DepEd runs teacher
professional development in general. They are not the Daily Lesson Log
template, the lesson plan format, the subject-specific curriculum guides for
the learning areas actually attending, or the assessment/rubric templates
this INSET's hands-on lesson-planning work needs. That material remains the
steward's to supply, per D-002, and is not yet gathered as of this commit.

If any of this is used at all on 10 September, its most likely role is
competency-framework context (aligning a lesson plan to a specific PPST
indicator) — not as source material for the DLL/curriculum work itself.

## Provenance and rights

Sourced from `zenbanez/zenos-deped`, `evidence/sources/`, at its `main`
branch, unchanged since admission there (2026-08-11 for the PPST/TPD
booklets, 2026-08-12 for the KSA job aid). No learner, teacher, or school
identifying data — confirmed at admission in the source house and
re-confirmed here; these are reference and policy documents.

This is a private-repository-to-private-repository transfer between houses
the same steward controls, for the same real-world program (DepEd Tacloban
teacher professional development). It is not publication. Per this
workspace's own `references/README.md`, nothing in this folder is cleared
for redistribution or use outside this house, and this repository stays
private.
