# Local Adoption and Updates

An upstream release never owns a receiving house.

1. Pin an immutable upstream commit.
2. Compare its manifest, provenance, rights, and migration notes locally.
3. Record the proposed update under a local intent and delegation.
4. Preserve local deviations and evidence.
5. Run local checks and review the diff.
6. A local steward accepts, amends, or declines.

Upstream deletion, reorganization, or withdrawal must never delete local
institutional records. Export remains the repository's legible file tree.
